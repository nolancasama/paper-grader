# Example output

`demo_output/` is one class built by `python -m papergrader demo`. **Everything is
synthetic:** the students are invented, the grades were typed in, and no real
handwriting or printer was involved. It shows what the files look like. It says
nothing about grading accuracy or print alignment.

The class has seven students, each covering one scenario:

| Order | Scenario | Printed result |
|---|---|---|
| 1 | All correct | 100, PERFECT! stamp, embroidered border |
| 2 | One wrong (Japanese name) | 90, praise stamp |
| 3 | Three wrong | 70, red marks only |
| 4 | One unreadable answer | Marks elsewhere, score box blank, no art |
| 5 | Not inspected | Empty page, kept in its place |
| 6 | All correct, scanned upside down | 100, everything flipped to match the sheet |
| 7 | One partial credit | 95, praise stamp, △ |

Start with `proofs/`, then `demo-class-a_correction_PREVIEW_DO_NOT_PRINT.pdf`.
